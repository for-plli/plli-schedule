# 바쁘다 바빠 플리사회 🤍 (비공식 팬 제작)

플레이브 공식 일정과 플리(팬) 예매·예약 일정을 한 곳에서 보는 사이트예요.
사이트 주소: https://for-plli.github.io/schedule/

## 일정 추가하는 법 (GitHub 웹/앱에서 파일을 고치고 저장하면 몇 분 안에 반영돼요)
- `ticketing.txt` : 예매·티켓팅·예약 일정 → **플리 일정**
- `plave_extra.txt` : 공식 사이트에 아직 없는 플레이브 일정(공연 등) → **플레이브 일정**
- 공식 사이트(plave.global)에 올라온 일정은 하루 두 번 자동으로 들어와요. 직접 적은 플레이브 일정이 공식 일정과 같으면 직접 적은 쪽은 자동으로 빠져요.

## 알림용 캘린더 (개인용, 사이트에는 링크 없음)
- 구독 주소: https://for-plli.github.io/schedule/schedule.ics  (아이폰은 설정 → 캘린더 → 캘린더 계정 → 계정 추가 → 기타 → 구독 캘린더 추가)
- 플리 일정(`ticketing.txt`)과 플레이브 릴리즈가 들어가고, 일정이 있는 날 아침 9시와 시작 10분 전에 알림이 가요.
- 아이폰은 구독한 캘린더에서 '알림 제거'를 꺼야 알림이 와요. 알림이 필요 없는 일정은 줄 끝에 `| 알림없음` 을 붙여요.

한 줄 형식: `날짜 시간 | 제목 | 메모 | 링크`  (예: `2026-12-04 20:00 | 일반예매 | NOL | https://...`)

공식 공지를 팬이 보고 정리한 일정이라 틀릴 수 있어요. 공식 채널을 꼭 다시 확인하세요.
