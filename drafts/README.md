# 시안 보관함 (사이트에 올라가지 않음)

## mipo-timeline.html — 컴백 시즌 미공포 타임라인 (2026-11-27)
- 판매처 한 줄 = 신청 가능 기간 막대, 세로선 = 오늘. 가짜 데이터 30곳.
- 정해진 것: 왼쪽은 판매처 이름만, 줄 높이 26px, 오픈 순 정렬 기본(마감 빠른 순은 버튼), 마감된 곳은 회색으로 맨 아래.
- 날짜는 막대 안: 진행 중은 막대 끝에 `~14일`, 시작 전은 `18일 오픈`, 오늘·내일은 `오늘 마감`. 막대가 짧으면 `18일~`로 줄이고, 그래도 안 들어가면 막대 밖(오른쪽)으로.
- 미공포 종류(럭드, 영통 응모 등)는 막대 뒤 회색 글자. 오른쪽 공간이 없으면 막대 앞에.
- 아직 정할 것: 같은 업체 여러 종류일 때 줄 나누기/묶기, 마감 알림 여부, 만드는 시기(컴백 확정 후).
- 사이트에서는 `영상`처럼 컴백 시즌에만 `미공포` 버튼으로 전환하는 구조로 생각 중.

## mipo-timeline-v4.html — frontend-design 기준 재정리 (2026-11-27)
- 상단 줄 3개(요약·버튼 3개·범례) → 2줄: 제목 옆 정렬 토글(오픈 순/마감 순), 요약의 색 점이 범례 역할.
- 시간 축을 '그 달 1일~말일' 대신 '오늘 4일 전~마지막 마감'으로: 막대가 길어져 글자가 막대 안에 들어감.
- 신청 가능 막대는 지난 부분을 연하게, 남은 부분만 진하게: 남은 기간이 한눈에.
- 진행 중 날짜는 모두 오늘 선 바로 옆에서 시작 → 세로로 한 줄 정렬. 오픈 예정은 오픈일에서 시작.
- 줄 구분선 대신 주 단위(월요일) 세로 선, 마감된 곳은 '마감된 곳 4 ▾'로 접기.

## mipo-timeline-v5.html — 가로 스크롤 + 종류 오른쪽 칸 (2026-11-27) ← 현재 기준안
- 왼쪽 판매처 이름, 오른쪽 종류 칸은 고정. 가운데 막대 영역만 옆으로 밀어서 봄 (하루 16px).
- 처음 열면 오늘 2일 전부터 보이게 자동 스크롤. 양 끝은 살짝 흐려져서 더 있다는 걸 알려 줌.
- 날짜는 12/14처럼 월/일로 (12월 말~1월 초에 걸쳐도 헷갈리지 않게). 막대에 안 들어가면 막대 뒤에.
- 가짜 데이터는 실제처럼 기간 10~18일로.
- 상세 팝업(줄 어디를 눌러도 열림): 판매처 이름 + 종류 태그 / 신청 기간(요일·시각) + 남은 날 / 앨범·가격·조건 / '구매처 열기' 버튼.
  - 남은 날 문구: 진행 중 '마감까지 6일', 오늘·내일 '오늘 23:59 마감', 시작 전 '2일 뒤 오픈'.
  - 더 넣을 후보: 특전 이미지, 1인 구매 제한, 배송 시기, 응모 발표일.

## mipo-v6 — 사이트 디자인에 맞춘 버전 (2026-11-27) ← 현재 기준안
- `mipo-v6-inject.js`: 실제 사이트(docs/index.html)를 연 뒤 실행하면 미공포 화면이 붙는 시안 스크립트. 사이트 CSS 변수(--f, --f-bg, --f-bar, --f-fg, --line, --muted)만 사용 → 다크 모드 자동.
- 필터·영상 옆에 `미공포` 버튼(켜지면 검정, 영상 버튼과 같은 모양). 켜면 월 이동 줄·달력·범례 대신 타임라인.
- 요약 줄은 범례와 같은 모양(작은 네모 + 글자 + 개수). 오늘 표시는 달력의 '오늘' 검정 동그라미처럼 검정 알약.
- 줄 구분선은 달력 주 구분선과 같은 색. 막대 모서리 6px(달력 칩과 같게).
- 상세 팝업은 달력 날짜 팝업 그대로: 큰 제목 + 종류 태그 / 분홍 일정 카드(마감일·시각·기간·남은 날) / 앨범·가격·조건 / 링크 버튼.
- 색: 인디고로 결정 (라이트 #7f8fe6 + 흰 글자 / 다크 #8d9cec). 퍼플은 빨강(마감 임박)과 안 어울려서 바꿈. 막대 안 글자는 진한 색 쓰지 않기(가독성).
  - 레이아웃이 달력과 완전히 달라서 플레이브 파랑과 계열이 비슷해도 괜찮다고 판단.
- 같은 판매처 1차·2차: 한 줄에 막대 여러 개, 막대 안에 `1차 ~12/18`, `2차 12/21 오픈`. 팝업 태그에 `홀로 포카 · 2차`.
- 공구처럼 다른 판매 방식: 줄을 따로 두고 이름 옆에 `공구` 작은 태그. 팝업 제목 `판매처 H 공구`.
- 남은 과제: 이름이 길면 `공구` 태그가 잘림 → 실제 판매처 이름 길이 보고 이름 칸 폭 정하기.
- 구매 체크(나 혼자 쓰는 기능): 판매처 이름 앞 동그라미를 누르면 구매 완료. 체크한 줄은 막대·글자가 흐려짐. 팝업에도 `구매 완료로 표시` 버튼.
  - 요약 줄 오른쪽에 `✓ 구매 완료 4 / 32`.
  - 저장은 그 브라우저(localStorage, 키 `plli-mipo-bought`)에만. 다른 폰·다른 사람에게는 안 보임. 사이트 데이터 지우면 사라짐.
  - 1차·2차는 회차별로 따로 체크(팝업 버튼). 이름 옆 동그라미는 그 줄 전체.
  - 사이트를 다른 팬과 공유 중이라, 실제로 붙일 때는 미공포 버튼 자체를 나만 보이게(주소에 ?me 같은 비밀 표시)할지 정해야 함.
- 색 역할 분리(2026-11-27): 퍼플 = 아직 할 일(신청 가능·오픈 예정), 검정 = 내가 한 것(체크 동그라미, 팝업 `✓ 구매 완료` 버튼, 오늘 선), 회색 = 끝난 일.
  - 구매 완료 줄: 막대가 회색으로 바뀌고 막대 안 글자가 `✓ 구매 완료`, 이름에 옅은 취소선.
- 마감 임박(오늘·내일 마감): 검정 테두리 대신 빨간 막대 + 빨간 글자(라이트 #e5484d / 다크 #f2555a). 요약 줄 '오늘 마감' 점도 빨강.
- 체크 동그라미 18px → 14px.
